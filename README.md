The entry is the entrant's own make.fun username, one word and nothing
else: `thofix-05`.

`main.py` (Python 3.13, standard library only) writes exactly that
username — 9 characters, no trailing newline, no spaces, no extra
text — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`
when that variable is not set). The judge compares usernames two at
a time and picks the funnier or more interesting one.

Bounty: https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae

## Run it

```sh
python3 main.py
```

With an explicit output directory:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-word-test-output python3 main.py
cat /tmp/one-word-test-output/entry.txt
```
